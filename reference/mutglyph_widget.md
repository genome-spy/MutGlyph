# Create a MutGlyph widget

Create a MutGlyph widget

## Usage

``` r
mutglyph_widget(spec, width = NULL, height = NULL, elementId = NULL)
```

## Arguments

- spec:

  A complete GenomeSpy specification.

- width, height:

  Widget dimensions.

- elementId:

  Optional element ID.

## Value

An htmlwidget containing the GenomeSpy specification.
